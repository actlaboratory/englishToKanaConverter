# 辞書の調査・修正記録

## 1. このドキュメントについて

[dictionary-policy.md](./dictionary-policy.md)に定めた各規則が、**どういう調査に基づいて決まったのか**を記録したものである。実際に何をどう修正したか、途中でどういう誤りを犯したかも含む。

方針そのものを知りたい場合は[dictionary-policy.md](./dictionary-policy.md)を読めば足りる。本ドキュメントは、規則の妥当性を検証したい人、同種の作業を再び行う人のためのものである。

作業は[issue #5](https://github.com/actlaboratory/englishToKanaConverter/issues/5)への対応として行った。`dictionaries/phrases.json`（約49,000件）を中心に、カテゴリごとに調査・修正した。

## 2. 調査の基本手法

`phrases.json`の各エントリー（見出し語Kと読みR(K)）について、Kが既に登録されている別の語の組み合わせ（接頭辞＋基語、基語＋接尾辞、基語＋基語）として分解できる場合に、その組み合わせの読みを単純連結したものとR(K)を比較する、という方法を基本とした。

**この手法で分かったことが1つある。** 屈折語尾（`-s`/`-ed`/`-ing`/`-ly`）について単純連結と一致しないケースが数千件見つかったが、その大半は英語として正しい音便変化だった（`abated`は`アベイトゥ`＋`ドゥ`ではなく`アベイティドゥ`）。**既に登録されている約49,000件は、実際の英語の発音パターンに概ね忠実に統一されている。** 一致しないこと自体は問題を意味しない。

## 3. カテゴリ別の調査結果

### 3.1 否定接頭辞＋母音（33件修正）

`un-`＋母音始まりの語を洗い出すと、同一の音韻環境にもかかわらず3パターンが混在していた。

| パターン | 例（修正前） |
| --- | --- |
| A: ンを脱落させ直接リンク | `unable`→`アネイブル`、`unarm`→`アナーム` |
| B: ンを保持しつつ子音を挿入 | `unaware`→`アンナウェアー`、`unavailable`→`アンナベイラブル` |
| C: ンを保持しそのまま母音に接続 | `unavoidable`→`アンアボイダブル` |

`in-`でも同様で、`ineptitude`→`ニネプティチュードゥ`のような脱字も見つかった。C型に統一し33件（`un-`16件、`in-`17件）を修正した。

**`re-`接頭辞（約250件）がほぼ全件一貫していることは、統一可能性の根拠にならない。** `re`は既に母音で終わる1モーラ（`リ`）であり、直後に母音が続いても読み方の選択肢が存在しない。一方`un`/`in`の`N`は撥音であり、「ンのまま残す」か「ナ行に同化する」かという本当の選択の余地がある。この違いを見落として`re-`を根拠にするのは誤りである。

不統一の原因を、本リポジトリでの`bep-eng.dic`と[HISSの読み辞書](https://github.com/actlaboratory/HISS-dictionary)の統合に求めるのも正確ではない。HISS由来の語は多くなく、辞書の大部分は`bep-eng.dic`に由来する。`bep-eng.dic`自体がGPL化以前から長い歴史を持ち複数のメンテナーを経たデータであり、撥音の実現方法という複数の答えがあり得る箇所で担当者ごとに異なる選択がなされたまま残った、というのが実態に近い。元データは[bep-argv/bep-ss](https://github.com/bep-argv/bep-ss)にある。

### 3.2 `V`の読み（1,148件修正）

`ヴ`を含むのは`phrases.json` 1,147件と`words.json` 1件（`violets`）のみだった。同一語族内で混在している例が多数あった。

| 語族 | 修正前の状態 |
| --- | --- |
| `govern-` | `ガヴァン`／`ガヴァメントゥ` に対し `ガバナンス`／`ガバメンタル` |
| `-volve` | `ディボルブ`／`インボルブ` に対し `コンヴォルヴ`／`リヴォルヴァー` |
| `conserve` | `コンサーブ` に対し活用形が `コンサーヴドゥ`／`コンサーヴィング` |
| `traveler`/`traveller` | 米式`トゥラベラー` に対し 英式`トゥラヴェラー` |

バ行に統一した結果、これらはすべて解消した（`traveler`と`traveller`はどちらも`トゥラベラー`になった）。

**慣用読みの例外は1件も必要なかった。** 変換結果はいずれも標準的な日本語表記に近づく方向に働いた（`ヴィーナス`→`ビーナス`、`インタヴュー`→`インタビュー`）。

**`granitic`→`ヴラニティク`のみ機械変換から除外した。** 「読みに`ヴ`があるのに見出し語に`V`がない」という条件で事前に洗い出したところ発見できたもので、`ヴ`は`グ`の誤植だった。機械変換すると`ブラニティク`という誤りになるため、`granite`→`グラニットゥ`を根拠に`グラニティク`へ個別修正した。**この事前スクリーニングがなければ誤変換していた。**

### 3.3 `th`の読み（8件修正）

`th`を含む見出し語は約1,368件で、大半の語族は既に一貫していた。見つかった不統一は2種類。

* **表記ゆれ**: `think`→`スィンク`系なのに`bethink`→`ビシンク`、`thick`系なのに`thickener`→`シックナー`、`thing`→`スィング`なのに`anything`→`エニスイング`。語族の多数派に合わせて3件修正。
* **有声/無声の誤り**: `strengthen`→`ストゥレングスン`（無声）に対し`lengthen`→`レングザン`（有声）。同じ`-then`接尾辞で扱いが逆転していた。直接対照できる語があるものに限り5件修正した。

### 3.4 語末`-Y`の長音（1,175件＋46件修正）

語末`-Y`の4,312件で、同じ音が`ー`（2,776件）／`イ`（1,467件）／`ィ`（44件）の3通りに書き分けられていた。**同一の接尾辞の中ですら割れていた。**

| 接尾辞 | `ー` | `イ` |
| --- | --- | --- |
| `-ically` | 156件 | 93件 |
| `-ability` | 66件 | 26件 |
| `-ationally` | 9件 | 17件（ここだけ`イ`が多数派） |

`ー`に統一して1,175件を修正した。

**「末尾の`イ`を`ー`に置換」という一括処理をしていたら337件を破壊していた。** 語末の`イ`は、直前がイ段でなければ長音ではなく二重母音だからである（`ally`→`アライ`、`annoy`→`アノイ`）。直前がイ段の場合のみ変換する形で除外し、全件を検証した。

修正後も長音化されていない語が54件残った。同じ接尾辞の兄弟語が多数派としてどうなっているかを集計し（`-bility`は134件中133件が長音、`-dity`は31/31）、46件を修正、7件を据え置いた。`icky`のみ促音も欠けていたため`イキ`→`イッキー`とした。

**`every`は教訓的な例である。** 兄弟語の集計は`-very`が一致する`bravery`・`delivery`を根拠に長音化を「支持」したが、これらは`brave`+`ry`・`deliver`+`y`であって`every`は`e`+`very`ではない。**接尾辞が文字列として一致するだけでは根拠にならず、語の成り立ちを確認する必要がある。**

### 3.5 日本語として成立しない読み（15件修正）

カタカナ表記として起こり得ない仮名の並びを走査して発見した。すべて修正前から存在していたバグである。

* 長音記号・撥音・促音の誤り13件（`beanpole`→`ビンーポール`、`busybody`→`ビジーボディーー`、`gosh`→`ガーシュッ`、`kinn`→`キンン`、語頭が小書き`ェ`の5件）
* 読みそのものの誤り2件（`antagonistically`→`アンタゴニスティカル`は`-ly`が脱落、`irreducibly`は語末長音が欠落）

**走査条件として「小書き仮名の連続」を試したが使えなかった。** `ティッドゥ`（`ィ`＋`ッ`）や`キャッツ`のような正当な拗音・促音表記を1,179件も誤検出するためである。有効な条件は、`ーー`の重複、語頭の`ー`、`ン`直後の`ー`、語頭の小書き仮名、語末の`ッ`、`ッ`/`ン`の重複である。

### 3.6 語末が`ト`・`ド`のままだった語（43件修正）

**単純な文字列検索では対象を絞れない。** 語末が`ト`のエントリーは63件あるが、大半は`alto`→`アルト`、`proto`→`プロト`のように`ト`が語末子音/t/ではなく音節/to/を表すもので、そもそも対象外である。見出し語が母音で終わるものを除外すると、真の候補は`ト`21件・`ド`23件だった。

残った44件の多くに辞書内の直接的な反証があった。

| 現状 | 反証 |
| --- | --- |
| `Stamford`→`スタンフォード` | `Stanford`→`スタンフォードゥ` |
| `Mohammed`→`モハメド` | `Mohamed`→`モハメドゥ`（同じ名前の綴り違い） |
| `Bollywood`→`ボリウッド` | `Hollywood`→`ハリウッドゥ` |
| `period`→`ピリオド` | `method`→`メソッドゥ` |

43件を修正し、`authz`→`オースゼット`のみ据え置いた（`ゼット`は英字`Z`の読みであって語末子音ではない）。

**この作業で方針の記述の誤りが判明した。** 当初「人名・地名で慣用的な形がある場合」を原則2の例外として挙げていたが、辞書は`Richard`→`リチャードゥ`、`England`→`イングランドゥ`のように英語圏の人名・地名にも一貫して原則1を適用していた。`シェパード`・`スタンフォード`は慣用ではなく単なる不統一だった。

### 3.7 語中の/oʊ/（324件修正）

**機械的な一括変換ができない。** 理由は3つある。

1. **`オー`から/oʊ/と/ɔː/を区別できない。** `north`→`ノース`（据置）と`total`→`トータル`（変換）は仮名の上では同じ「オ段＋`ー`」である。
2. **1語の中で扱いが分かれる。** `also`→`オールソー`は前半の`オー`が`al`由来の/ɔː/で据置、後半の`ソー`が`so`由来の/oʊ/で変換となる。
3. **決め手が語の由来であり、綴りから導けない。** 見出し語が`O`で終わり読みも「オ段＋`ー`」で終わる（最も判定が確実なはずの条件）131件を抽出すると、日本語のローマ字が約90件（`Ando`＝安藤、`Endo`＝遠藤、`judo`＝柔道）、イタリア語等が数十件で、**英語は10数件しかなかった**。`Ando`・`Aldo`・`ammo`を綴りから区別する手段はない。

対象は「オ段＋`ー`」を含む3,092件・3,130箇所ある。仮に95%の精度で機械変換しても約150件の新規の誤りを作ることになり、既存の不統一より悪化する。

そこで、信頼できる/oʊ/の綴り（`oa`・`ow`・`old`・`O`＋子音＋`E`・`-osis`・`-oma`）を持ち、かつ/ɔː/を示す綴り（`au`・`aw`・`alk`・`all`・`or`＋子音・`ough`）を含まない語を抽出し、**全件を目視して除外リストを作る**手順を取った。「オ段＋`ー`」が2箇所以上ある語は自動変換から外した。

除外した主な理由は、英語以外に由来（`Beethoven`・`Bologna`・`Noto`）、/oʊ/ではない母音（`gone`は/ɒ/、`oven`は/ʌ/、`losted`は/ɔː/、`doll`は/ɒ/）、`オー`が英字`O`の読み（`iostat`）である。

第3バッチでは除外条件から**語末の`or`**を外した。`motor`のように語末`or`が/ər/にすぎない語まで弾いていたためである。85件が該当したが大半は既に除外済みの語の再浮上で、新規は12件だった。

### 3.8 語末の/oʊ/（120件修正）

ここで**2度の誤った判断**をした。経緯を記録しておく。

**誤り1**: 語中の/oʊ/の第2バッチで常用語を手作業で補う際、`echo`・`Buffalo`・`hippo`・`limo`・`ammo`が語末という別の環境にあることを確認せず`オー`→`オウ`に変えた。

**誤り2**: それを是正しようとして、常用語47語のサンプルから「短い形が36対6で圧倒的多数派」と判断し、元から`オウ`だった6件（`hero`・`solo`ほか）まで変えた。語末`-O`の語を全数（861件）で数え直すと**短い435（50%）／`オウ`249（28%）／`オー`169（19%）**で、`オウ`は少数派の逸脱ではなかった。11件すべてを差し戻した。

**さらに数字自体にも2つの誤りがあった。**

第1に、`オー`群の約半数は/oʊ/ですらなかった。`bamboo`→`バンブー`、`zoo`→`ズー`のような`-oo`の語と、`into`→`イントゥー`、`undo`→`アンドゥー`のような`do`/`to`/`who`/`two`系は/uː/であって`ー`が正しい。47件を除くと**短い393（56%）／`オウ`248（35%）／`オー`49（7%）**となる。

第2に、`オー`を「7%の少数派だから解消すべき」と考えたのが誤りだった。実際に寄せる作業を行うと`Nintendo`→`ニンテンド`、`mango`→`マンゴウ`、`Shinto`→`シント`、`bravo`→`ブラボ`となり、**日本語として定着した正しい形を壊す**結果になった。この変更は破棄した。

逆に多数派である`オウ`248件に、`cello`→`チェロウ`、`cargo`→`カーゴウ`、`euro`→`ユーロウ`、`motto`→`モットウ`、`stereo`→`ステリオウ`、`silo`→`サイロウ`のように**日本語では別の形が定着している語が多数含まれていた**。定着形が明確にある120件を修正し、分布は短い507／`オウ`128／`オー`72になった。

**この一連の経緯から得られた教訓**は次の2つである。

* **分布を論拠にするなら全数を数えること。** 常用語だけを見ると定着した短い形に偏り、専門語や固有名詞に多い`オウ`形が視野から外れる。
* **ただしそれは必要条件にすぎない。分布は「どこが揺れているか」を示すだけで、「どちらが正しいか」は示さない。** 語末`-O`では件数の多寡と正しさが逆転していた。

### 3.9 日本語のローマ字の削除（383件削除）

`phrases.json`には日本語をローマ字表記した見出し語が多数登録されていた。これは、この辞書がVSUで発展していた時代に使われていたDOS用の日本語スクリーンリーダーVDMが、**ローマ字を読み下す仕組みを持たなかった**ためである。ローマ字をカナで読ませるには辞書に登録するしかなかった。

**「エントリーを削除すればローマ字変換に任せられる」は成り立たない。** 変換は辞書引き（`_partsToKana`）が先で、失敗した場合のみローマ字変換が動くため、`phrases.json`内の英単語が部分一致すると誤った読みが確定する。

| 見出し語 | 削除した場合 | 分解のされ方 |
| --- | --- | --- |
| `bando` | `バンドゥー` | `ban`＋`do`（英語のdo） |
| `codera` | `コッドゥエラ` | `cod`＋`era` |
| `aridome` | `アリドウム` | `ari`＋`dome` |

したがって削除の可否は、**実際に削除した状態で変換して読みを比較する**という実測でしか判断できない。

選別手順は次の通り。

1. ローマ字変換の結果が登録読みと一致する（長音記号の有無を除く）エントリーを抽出 … 1,220件
2. 一括削除した状態で全件変換 … 破綻する61件を除外（`baton`→`バットゥオン`、`heroin`→`ヒーロウイン`、`literacy`→`ライトゥレイシー`。いずれも英語）
3. **日本語のローマ字には`L`・`V`・`X`・`Q`が現れない**ことを利用して305件を機械的に除外
4. 残る854件を全件目視して選別

**「ローマ字変換で再現できる」ことは削除の必要条件であって十分条件ではない。** `body`→`ボディー`、`family`→`ファミリー`、`battery`→`バッテリー`はいずれもローマ字変換が同じ読みを返すが偶然にすぎず、英語である以上`roman.json`の変更で壊れる状態にすべきではない。

削除は4回に分けて行った。

* **318件**（`phrases.json`）… 230件は読みが完全に同一、88件は長音記号が失われる（`Ando`→`アンドー`が`アンド`）。ローマ字`Ando`に「う」が無い以上復元できない情報であり、辞書を軽くすることを優先して許容した。
* **27件**（`words.json`）… `Tokaido`→`トウカイドウ`、`Satomi`→`サトミ`など。`onyaku`→`オンヤク`のみ据え置いた（削除すると`オニャク`となり、これは長音欠落ではなく`nya`を拗音として読む**誤読**である）。`Toke`→`トウク`は削除により`トケ`となるが、土気は「とけ」なので改善にあたる。
* **15件**… 長音を`ー`ではなく`ウ`・`オ`で書いていたため条件に掛からなかったもの（`Ito`→`イトウ`、`Tojo`→`トウジョウ`）。条件を緩めると74件該当したが**大半は英語**で、`aroma`→`アロウマ`、`nobody`→`ノウボディー`の`ウ`は日本語の長音ではなく**英語の/oʊ/**（3.7節で統一したもの）だった。
* **18件**… 最終掃討。`popai`→`ポパイ`（Popeye）、`popura`→`ポプラ`（poplar）、`poruno`→`ポルノ`、`osero`→`オセロ`（Othello）、`doragon`→`ドラゴン`のように、**英語→カタカナ→ローマ字という二重の変換**を経たものが目立った。

**試して失敗した識別方法を2つ記録しておく。**

* **日本語の音節構造として成立するか**で絞る … 1,103件が該当したが、`abase`・`again`・`amaze`・`animation`のように英語の大半も日本語の音節に分解できてしまう。
* **日本語ローマ字に特徴的な綴り**（`tsu`・`ryu`・`kyo`・`oo`・`uu`）で絞る … 2,061件が該当したが、`tu`が`actual`・`adventure`を、`oo`が`aloof`・`afoot`を拾う。

結局、ローマ字変換との往復一致を実測した上で全件を目視するのが唯一有効だった。

### 3.10 `do`を`words.json`へ移動

3.9節で削除できなかった`bando`・`bundo`・`dando`・`haido`・`mando`は、いずれも`do`→`ドゥー`が部品として使われることが原因だった。`words.json`は完全一致でのみ使われ部品にならないため、`do`をそちらへ移せば解決する。同型の`to`→`トゥー`と`ado`→`アドゥー`は既に`words.json`にあり、`do`だけが取り残されていた。

ただし単純に移すと`do`を部品としていた英語が読めなくなる。実測すると`undo`→`ウンド`、`overdo`→`オーブイイーアールディーオー`のように、`_partsToKana`が丸ごと失敗して最終手段のスペルアウトまで落ちた。そこで移動と同時に`undo`・`outdo`・`overdo`・`misdo`・`doable`・`hairdo`を`phrases.json`へ登録した。

**同じ手口が他の短い語にも使えるかを検証したが、`do`以外に移動すべき語はなかった。**

| 語 | 移動した場合の改善 | 劣化 |
| --- | --- | --- |
| `on` | 1件 | 3件（`onboard`・`onload`・`onclick`がスペルアウトに転落） |
| `in` | 0件 | 3件（`inbox`・`inline`・`inland`） |

`-on`/`-in`で終わる語の大半（`pylon`→`パイロン`、`tannin`→`タニン`）は元から正しく変換されており、一方`on`・`in`は英語の接頭辞として極めて生産的である。`do`が特殊だったのは、(1)日本語の姓・地名に`-do`で終わるものが多く、(2)その直前部分（`ban`・`dan`・`man`）がたまたま英語として登録されており、(3)`do`を部品とする英語が数えられる程度に少ない、という条件が重なったためである。
